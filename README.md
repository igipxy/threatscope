# 🛡️ ThreatScope

## 📌 Overview
A full-stack threat intelligence dashboard that allows users to scan URLs and domains for malicious activity using the VirusTotal API.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** SQLite (for caching scan results)
- **API:** VirusTotal API v3
